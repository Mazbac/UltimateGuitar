# Backlog

This file contains accepted ideas that are not part of the current vertical slice or release.

## Intake rule
Classify new ideas as correction, feature, architecture change, design-system change, product-experience change, security issue or research. Assess release relevance and dependencies before changing the current objective. Durable preferences still update their owning product/design source.

## Accepted post-v0.1 items
- Additional palm-mute picking positions/directions as recorded.
- Sustains/long notes.
- Power chords in recorded length variants.
- Slides, vibrato and lead articulations.
- String/fret noises and scrape/release details.
- Optional stereo-double workflow using the independent Left and Right banks after the single-bank engine is verified.
- Smarter performance/fingering logic only after the direct sparse string mapping is proven reliable.
- Disk streaming or tiered cache if measured future sample-bank size makes shared preload impractical.
- macOS/AU/CLAP targets only after the Windows VST3 release is stable.
- Public product naming/branding before any external commercial distribution.
